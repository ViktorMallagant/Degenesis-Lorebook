# Well-described Clan pages

Use Pneumancers as the reference for future Clans with full lore, ranks, and equipment.

- Keep the shared Cult black/red background, heading fonts, red kickers, and alphabetical Clan sidebar.
- Place the white Clan emblem directly after the hero heading. Preserve sourcebook vector geometry when available.
- Put the homeland, region, and tech panels below the hero introduction, followed immediately by the Skill Bonuses callout and then the source citation. List creation skills as bullets.
- Preserve the sourcebook's briefing text and paragraph structure. Display supplied rank art in the right-hand `.briefing-art` column of `.briefing-layout`, using the same sticky behavior as Cult pages. Show it independently of the selected rank.
- Reuse the compact 925px Clan tree, preserving all branches and centered vertical connectors. Rename the eight ranks according to the user's mapping; keep source prerequisites, effects, and equipment in the selectable detail panel.
- Include Clan-specific Potentials when present in the requested source pages.
- Group equipment into the usual collapsible categories, with each item's full description and stats on its card. Put vehicle artwork with its vehicle entry. Do not duplicate these stats in a separate bottom chart.
- Keep the existing responsive Cult behavior and verify the desktop layout, rank selection, image loading, and asset links before publishing.

This describes the convention for new pages; it does not authorize changing earlier Clan pages beyond the user's requested edits.
